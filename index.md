## 🖥️ Using MemCloud

1. **Start the Daemon**: Once the application is running, MemCloud will start the daemon process. This process manages the pooled memory across devices.

2. **Connect Devices**: Ensure other devices on your local network run MemCloud. They will automatically find each other. You can view connected nodes from the application interface.

3. **Storing Data**: Now you can start sending data to your MemCloud. The data will be stored across the pooled RAM of all connected machines.

4. **Accessing Data**: Use the application interface to view stored data and manage it. You can add or remove data easily.

## 📝 Frequently Asked Questions

### Can I use MemCloud on any operating system?

Yes, MemCloud works on macOS, Windows, and Linux.

### Is my data secure in MemCloud?

MemCloud does not save data permanently. However, always be cautious when sharing sensitive information over a network.

### How do I troubleshoot issues?

If you encounter any problems, check the following:
- Ensure all devices are on the same network.
- Make sure that the firewall settings allow MemCloud to communicate.
- Restart the application if any issues persist.
